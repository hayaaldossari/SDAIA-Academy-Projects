# AI Training Assignments and projects

This repository contains my assignments and projects developed as part of the **Generative AI Solutions Development** training program.

The projects focus on practical applications of generative AI, text embeddings, semantic search, vector databases, and Retrieval-Augmented Generation (RAG).

## Assignments

### Assignment 1 — Text Embedding and Semantic Search

A foundational text processing and semantic search pipeline using a dataset about **Saudi Projects and Vision 2030**.

The assignment covers:

* Text chunking
* Tokenization
* Text embeddings
* Cosine similarity
* Semantic search
* Top-K retrieval
* Generative AI-based answer generation

[View Assignment 1](./Assignment-1-Text-Embedding-RAG/)
